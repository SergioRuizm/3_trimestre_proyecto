# LoveCode 

Aplicación web de tipo "match" orientada al mundo tecnológico. Los usuarios pueden registrarse indicando las tecnologías que conocen, visualizar otros perfiles y dar likes. Cuando dos usuarios se dan like mutuamente, el sistema genera un match automáticamente.

## Tecnologías utilizadas

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java con Spring Boot
- **Base de datos:** MySQL (MariaDB en máquina virtual Debian)
- **Control de versiones:** Git / GitHub

## Estructura del repositorio
backend/        # Código Java con Spring Boot
frontend/       # HTML, CSS y JavaScript
database/       # Script SQL de la base de datos
scripts/        # Scripts de backup y arranque
documentacion/  # Memoria técnica del proyecto

## Funcionalidades

- Registro de usuarios con tecnologías
- Inicio de sesión
- Visualización de perfiles
- Sistema de likes y matches automáticos
- Notificación cuando hay un nuevo match
- Ver mis likes y matches
- Mi perfil
